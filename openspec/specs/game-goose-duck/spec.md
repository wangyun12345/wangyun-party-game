## 新增需求

### 需求:游戏开始时自动分配鹅鸭杀身份
系统必须在游戏开始时随机分配玩家身份（鹅/鸭），且每个玩家只能看到自己的身份，MVP阶段只包含基础两种身份。

#### 场景:玩家查看自己的身份
- **当** 游戏开始
- **那么** 每个玩家界面显示其专属身份（鹅或鸭），其他玩家的身份不可见

#### 场景:鸭子查看同伴列表
- **当** 游戏开始，玩家身份为鸭
- **那么** 该玩家界面额外显示其他所有鸭子玩家的昵称列表

### 需求:玩家可以发起紧急会议
系统必须允许任意玩家在游戏进行中发起紧急会议，会议开始后所有玩家进入讨论与投票环节。

#### 场景:发起紧急会议
- **当** 玩家点击"发起紧急会议"按钮
- **那么** 所有玩家界面显示会议发起通知和发起人昵称，进入讨论阶段

#### 场景:讨论阶段倒计时
- **当** 进入讨论阶段
- **那么** 所有玩家界面显示倒计时（默认60秒），倒计时结束后自动进入投票阶段

### 需求:会议后所有玩家投票驱逐嫌疑人
系统必须允许所有存活玩家在投票阶段选择驱逐一名玩家或选择跳过投票，结果公示。

#### 场景:得票最多的玩家被驱逐
- **当** 所有玩家完成投票，某玩家得票数唯一最多
- **那么** 该玩家被驱逐出局，公示其真实身份（鹅或鸭），然后继续游戏

#### 场景:平票时无人被驱逐
- **当** 所有玩家完成投票，最高票数由多名玩家并列
- **那么** 本次无人被驱逐，显示平票提示，继续游戏

#### 场景:跳过投票选项
- **当** 玩家选择"跳过"而非选择候选人
- **那么** 该玩家本次投票计为弃权

### 需求:达到胜利条件时游戏结束
系统必须根据存活的鹅与鸭的数量判断胜负。

#### 场景:鸭子数量等于或超过鹅的存活数量时鸭子胜利
- **当** 有人被驱逐后，存活鸭子数量 ≥ 存活鹅数量
- **那么** 鸭子阵营胜利，揭示所有玩家身份，显示胜负结果

#### 场景:所有鸭子被驱逐时鹅胜利
- **当** 有人被驱逐后，场上已无存活鸭子
- **那么** 鹅阵营胜利，揭示所有玩家身份，显示胜负结果

### 需求:游戏结束时揭示所有身份
系统必须在游戏结束时显示每位玩家的真实身份。

#### 场景:游戏结束揭示界面
- **当** 任意一方满足胜利条件
- **那么** 所有玩家界面显示胜负结果及全体身份揭示，房主可选择返回大厅或再玩一局
