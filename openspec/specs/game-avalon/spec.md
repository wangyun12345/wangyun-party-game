## 新增需求

### 需求:游戏开始时自动分配阿瓦隆角色
系统必须在游戏开始时根据玩家人数和房主配置，随机分配阿瓦隆角色（梅林、派西维尔、莫德雷德等），且每个玩家只能看到自己的角色。

#### 场景:正义阵营玩家查看角色
- **当** 游戏开始，玩家为梅林
- **那么** 该玩家界面显示其角色为"梅林"，并显示所有邪恶阵营玩家的昵称

#### 场景:邪恶阵营玩家查看角色
- **当** 游戏开始，玩家为邪恶阵营成员
- **那么** 该玩家界面显示其角色，并显示其他邪恶阵营玩家的昵称

#### 场景:普通玩家无法看到他人角色
- **当** 游戏开始，玩家为普通骑士
- **那么** 该玩家界面只显示"骑士"，不显示任何人的阵营或角色

### 需求:领袖提名队伍
系统必须允许当前领袖（Leader）选定指定数量的玩家组成任务队伍并提交提名。

#### 场景:领袖选择队伍成员
- **当** 领袖点选玩家头像加入/取消队伍，且选择人数达到当前任务要求人数
- **那么** "提交提名"按钮变为可点击状态

#### 场景:提交提名进入投票阶段
- **当** 领袖点击"提交提名"
- **那么** 房间进入投票阶段，所有玩家界面显示提名的队伍成员，并展示赞成/反对按钮

### 需求:所有玩家对提名队伍进行投票
系统必须允许所有玩家在投票阶段对提名的队伍进行秘密投票（赞成/反对），并在所有人投票完成后公示结果。

#### 场景:投票通过，队伍出发执行任务
- **当** 所有玩家完成投票，赞成票数多于反对票数
- **那么** 系统公示投票结果，队伍成员进入任务投票阶段

#### 场景:投票失败，领袖轮换
- **当** 所有玩家完成投票，反对票数大于等于赞成票数
- **那么** 系统公示投票结果，领袖职位顺时针传递至下一位玩家，累计失败次数加一

#### 场景:连续五次提名被否决时邪恶方胜利
- **当** 同一轮任务连续5次提名投票失败
- **那么** 邪恶阵营胜利，游戏结束

### 需求:被选中的队员对任务进行秘密投票
系统必须允许被选中的任务队员对任务结果进行秘密投票（成功/失败），正义阵营玩家必须投成功。

#### 场景:任务成功
- **当** 所有队员完成投票，失败票数为0（或特殊规则条件下）
- **那么** 本轮任务成功，正义阵营得分加一

#### 场景:任务失败
- **当** 所有队员完成投票，存在至少1张失败票
- **那么** 本轮任务失败，邪恶阵营得分加一

### 需求:三轮任务结果决定游戏走向
系统必须跟踪每轮任务的成功/失败记录，正义方赢得3轮进入刺杀阶段，邪恶方赢得3轮直接胜利。

#### 场景:正义方赢得三轮任务进入刺杀阶段
- **当** 正义阵营累计赢得3轮任务
- **那么** 进入刺杀阶段，刺客玩家可以指认一名玩家是否为梅林

#### 场景:刺杀梅林成功时邪恶方翻盘
- **当** 刺客指认的玩家确实为梅林
- **那么** 邪恶阵营胜利，揭示所有角色

#### 场景:刺杀失败时正义方最终胜利
- **当** 刺客指认的玩家不是梅林
- **那么** 正义阵营胜利，揭示所有角色

### 需求:游戏结束时揭示所有角色
系统必须在游戏结束时展示所有玩家的角色和阵营。

#### 场景:游戏结束揭示界面
- **当** 任意一方满足胜利条件
- **那么** 所有玩家界面显示胜负结果及全体角色揭示，房主可选择返回大厅或再玩一局
