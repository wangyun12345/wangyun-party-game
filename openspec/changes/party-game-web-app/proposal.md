## 为什么

朋友聚会时需要一个随时能玩的桌游辅助工具：无需安装 App、无需注册账号，用手机打开链接即可加入同一个游戏房间，从而替代繁琐的纸牌和口头主持。

## 变更内容

- 全新开发一个基于 Web（H5 移动端适配）的多人桌游平台
- 初始内置两款游戏：**阿瓦隆（Avalon）** 和 **鹅鸭杀（Goose Goose Duck）**
- 无账号系统：玩家通过输入临时昵称直接进入游戏，房主自动获得控制权
- 平台架构设计支持后续扩展更多桌游（如瞎掰王等），无需改动大厅核心逻辑
- "房主即裁判"模式：房主设备负责运行游戏状态机逻辑，其他玩家订阅状态变更

## 功能 (Capabilities)

### 新增功能

- `lobby`: 房间大厅系统——创建/加入房间、玩家列表管理、游戏选择与开始控制
- `game-avalon`: 阿瓦隆游戏引擎——角色分配、组队提名、赞成/反对投票、任务成功/失败投票、梅林刺杀与胜负结算
- `game-goose-duck`: 鹅鸭杀游戏引擎——身份分配（鹅/鸭/特殊角色）、讨论期计时、举报/会议机制、投票驱逐与胜负结算
- `realtime-sync`: 基于 Supabase Realtime 的多玩家状态实时同步层
- `game-plugin-interface`: 桌游插件接口规范——统一的游戏接入契约，供未来扩展游戏使用

### 修改功能

（无，本次为全新项目）

## 影响

- **新增依赖**：React、TailwindCSS、Vite（前端构建）；Supabase（实时数据库 & BaaS）
- **平台**：移动端优先的 Web 网页，兼容主流手机浏览器（微信内置浏览器、Safari、Chrome）
- **无后端服务器**：所有游戏逻辑在房主客户端运行，Supabase 作为状态存储和广播层
- **无用户数据持久化**：游戏结束后房间数据可清理，不存储个人信息
